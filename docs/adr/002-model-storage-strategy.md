# ADR-02: Стратегия хранения и версионирования моделей и артефактов
- **Статус:** Принято (Accepted)
- **Контекст:** Веса моделей компьютерного зрения занимают от 50 до 500 МБ. Git не предназначен для хранения больших бинарных файлов.
- **Рассмотренные альтернативы:** 1. Хранение файлов моделей напрямую в Git. 2. Использование S3-совместимого хранилища (MinIO) или локальной папки с версионированием через DVC.
- **Решение:** Категорический запрет на хранение бинарных весов в Git. Файлы моделей хранятся локально или в MinIO, а в Git фиксируется только текстовый файл метаданных.
- **Обоснование:** Сохраняет скорость клонирования репозитория, предотвращает раздувание истории Git.
- **Последствия:** При развертывании на новом устройстве необходимо дополнительно скопировать файл модели, но это стандартная практика для Edge AI.

# ADR-01: Выбор режима инференса (Synchronous REST API vs Asynchronous Queue)
- **Статус:** Принято (Accepted)
- **Контекст:** Система визуального контроля работает на движущемся конвейере. Требуется мгновенная реакция на каждый кадр (SLA: p95 < 50 мс), чтобы успеть подать сигнал на отбраковку.
- **Рассмотренные альтернативы:** 1. Асинхронная очередь (Kafka/RabbitMQ). 2. Синхронный REST API (FastAPI).
- **Решение:** Выбран синхронный REST API.
- **Обоснование:** Для Edge-устройства с одним источником видеопотока синхронный вызов обеспечивает минимально возможную задержку (отсутствие сетевых накладных расходов на брокер). FastAPI с Uvicorn легко держит 20-30 RPS.
- **Последствия:** При резком пиковом скачке кадров возможна очередь запросов. Риск митигорируется настройкой worker_connections и отбрасыванием устаревших кадров.

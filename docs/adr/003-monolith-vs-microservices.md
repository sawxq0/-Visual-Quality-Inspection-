# ADR-03: Архитектурный стиль сервиса (Модульный монолит vs Микросервисы)
- **Статус:** Принято (Accepted)
- **Контекст:** Система развертывается на промышленном Edge-компьютере (IPC) в цеху, часто в условиях ограниченных вычислительных ресурсов и отсутствия стабильного подключения к корпоративному Kubernetes.
- **Рассмотренные альтернативы:** 1. Микросервисная архитектура. 2. Модульный монолит в едином Docker-контейнере.
- **Решение:** Модульный монолит в едином Docker-контейнере.
- **Обоснование:** Исключает сетевые задержки (gRPC/HTTP) между API и моделью, что критично для SLA < 50 мс. Упрощает деплой и мониторинг на Edge-устройстве.
- **Последствия:** Сложнее масштабировать только компонент инференса независимо от API, но для задачи контроля одного конвейера это избыточно.
